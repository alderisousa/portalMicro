# Portal Micro

Protótipo de plataforma para criação de páginas digitais para microempreendedores.

O Portal Micro permite que cada empreendedor crie seu próprio perfil comercial,
publique informações do negócio e futuramente disponibilize fotos e vídeos.

## Arquitetura

O projeto utiliza:

- React
- Vite
- TypeScript
- Supabase Auth
- Supabase PostgreSQL
- Supabase Storage
- Google OAuth

A publicação do frontend será realizada futuramente utilizando Vercel.
